# M.Tech Thesis

## Secure IoT Data Analytics via q-Sigmoid Enhanced Federated Learning for Threat Detection

This folder contains the complete M.Tech thesis documenting
the proposed q-Sigmoid enhanced Federated Learning framework
for IoT intrusion detection.

The thesis covers:

- Problem formulation
- Literature review
- q-Sigmoid mathematical formulation
- Federated Learning methodology
- IID and Non-IID experiments
- UNSW-NB15
- WUSTL-IIoT-2021
- CSE-CIC-IDS2018
- Experimental results
- Limitations
- Future research directions
