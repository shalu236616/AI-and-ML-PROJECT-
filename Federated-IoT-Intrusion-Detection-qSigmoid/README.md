# Federated IoT Intrusion Detection using q-Sigmoid

## Overview

This project presents a Federated Learning-based framework for
IoT intrusion detection using a Tsallis-statistics-based
q-Sigmoid loss function.

The work investigates the challenges of class imbalance and
non-IID data distributions in federated IoT cybersecurity.

## Proposed Approach

The framework includes:

- q-Sigmoid loss
- Tsallis statistics
- Federated Averaging (FedAvg)
- PerClient-q-Sigmoid
- IID and Non-IID federated learning
- Validation-based q selection
- Classification threshold calibration

## Datasets

Experiments were conducted using:

- UNSW-NB15
- WUSTL-IIoT-2021
- CSE-CIC-IDS2018

## Compared Methods

- Binary Cross-Entropy (BCE)
- q-Sigmoid
- PerClient-q-Sigmoid
- Generalized Cross Entropy (GCE)
- Focal Loss
